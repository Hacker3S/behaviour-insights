📖 Mathematical Formulations & Viva Reference Sheet (Click to Expand)
1. Continuous Random Variable (Netflix & Spotify)
f(x) = \frac{1}{\sigma\sqrt{2\pi}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}

Watch and listening durations are modeled as continuous real numbers X ∈ [0, ∞). The normal probability density function (PDF) models user clustering around the mean.

2. Discrete Random Variable (Amazon)
P(X = k) = \frac{\lambda^k e^{-\lambda}}{k!}

Click events represent discrete non-negative integer counts k ∈ {0, 1, 2, ...}. The Poisson distribution parameter λ is estimated directly by the sample mean.

3. Expected Value & Sample Variance
E[X] ≈ \bar{x} = \frac{1}{n}\sum x_i, \quad s^2 = \frac{1}{n-1}\sum (x_i - \bar{x})^2

The sample mean \(\bar{x}\) provides an unbiased estimator for E[X]. Bessel's correction (n-1) provides an unbiased sample variance estimator.

4. Empirical vs Model-Based Probability
P_{emp}(X \geq t) = \frac{\sum [x_i \geq t]}{n}, \quad P_{norm}(X \geq t) = 1 - \Phi\left(\frac{t-\mu}{\sigma}\right)

Comparing empirical observations against parametric distributions allows validating whether the theoretical model reliably approximates user behaviour.
